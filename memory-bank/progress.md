 # Progresso do Projeto: Revoluna

**O Que Funciona (Core Loop):**
- O fluxo principal para o médico está implementado e funcional.
  - Cadastro de novos usuários.
  - Login com múltiplos provedores.
  - Visualização da lista de vagas/plantões.
  - Sistema de candidatura para as vagas.
