# Revoluna 👨‍⚕️

**Revoluna** é um aplicativo móvel Flutter que conecta profissionais de saúde com oportunidades de trabalho em plantões médicos. O app facilita a busca e candidatura para vagas em hospitais de todo o Brasil.

## 🚀 Sobre o Projeto

O Revoluna é uma plataforma de staffing médico que permite:
- 👨‍⚕️ Cadastro completo de médicos
- 🏥 Visualização de vagas de plantão com informações detalhadas  
- 💰 Sistema de acompanhamento de pagamentos integrado
- 🔐 Autenticação segura com múltiplas opções de login

## ✨ Principais Funcionalidades

### 🔐 **Autenticação**
- Login por telefone ou e-mail (OTP), Google e Apple
- Cadastro em 3 etapas com validação de documentos
- Verificação de CPF e dados profissionais

### 👨‍⚕️ **Perfil Médico**  
- Dados pessoais e profissionais completos
- CRM, RQE e especialidade médica

### 🏥 **Sistema de Vagas**
- Listagem de plantões disponíveis
- Filtros por especialidade, data e localização
- Candidatura com um toque
- Acompanhamento de status em tempo real

### 📊 **Dashboard**
- Métricas pessoais de plantões
- Histórico de candidaturas
- Agenda de plantões confirmados
- Controle de pagamentos
